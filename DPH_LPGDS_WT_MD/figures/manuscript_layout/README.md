# Manuscript figure layout

The two lower-row panels are available at 88 × 96 mm each, designed to be placed side by side at full scale. A combined 180 × 96 mm layout provides a 4 mm gap between panels. Text is approximately 8 pt, with 600 dpi PNG exports and editable PDF/SVG versions. The background is white and grid lines have been removed.

The solvent-accessible surface area (SASA) panel retains the isolated-ligand reference line. The residue-contact heatmap reports occupancy for successive 100 ps windows of the 5 ns production trajectory. Data, analysis windows, distance thresholds, and color conventions were unchanged during figure layout.

For direct manuscript insertion, use `DPH_bottom_row_180x96mm.pdf`. Alternatively, use the separate 88 × 96 mm PDF panels, retaining the original aspect ratio. Original analysis figures remain available.
